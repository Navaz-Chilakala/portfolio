# Portfolio

Source for my personal site: **https://navaz-chilakala.vercel.app/**

A single static page in plain HTML, CSS and JavaScript, with no framework or build step. It includes a light and dark theme, an animated HTTP/2 traffic field in the hero, an expandable project index, link-preview (Open Graph) tags, and a contact form backed by Formspree.

| File | What it is |
|---|---|
| `index.html` | The page |
| `portfolio.css` | Styles, including the dark theme |
| `portfolio.js` | Theme toggle, mobile menu, hero animation, counters and contact form |
| `og-image.png` | Link-preview image (1200 × 630) |
| `Navaz_Chilakala_Resume.pdf` | The resume behind the "Download resume" button |

Deployed on Vercel; every push to `main` goes live.
